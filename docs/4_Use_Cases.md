# Сценарии использования justask

## UC‑1: Первый запуск студента (Onboarding)
- **Актор**: Новый студент, которому еще не загружены материалы курса.
- **Контекст**: Страница загружается, срабатывает `showOnboarding()`.
- **Экран**: Показывается приветственная карточка с четырьмя нейтральными sample‑вопросами:
  1. Объясни ключевые понятия из первой темы
  2. Разбери основное задание из материалов
  3. Покажи пример из материалов курса
  4. Какие требования или шаги описаны?
- **Действия студента**:
  1. **Читает** sample‑вопросы и решает, задать ли вопрос.
  2. **Нажимает ×** (крестик) → карточка убирается, `localStorage.setItem(ONBOARDING_KEY,"1")` и, если диалог пуст, появляется простое приветствие «Привет! Я ассистент курса justask».
  3. **Нажимает «Показать подсказку»** (кнопка помощи) → карточка снова появляется (если она была скрыта), состояние-dismissal сбрасывается.
- **Пост‑условия**: `hasCourseDocuments === false`; наboarding больше не показывается до очистки куков или повторного запуска курса.

## UC‑2: Студент задает вопрос (с материалами)
- **Актор**: Студент, у которого уже есть загруженные документы (через учителя или самостоятельно).
- **Контекст**: В диалоге уже есть AI‑карточки от предыдущих вопросов.
- **Действия**:
  1. Вводит вопрос в поле ввода `#userInput` (например, *«Как построить граф задач?»*) и нажимает **Send**.
  2. Система отправляет `POST /api/chat/stream` с JWT (или как гость).
  3. **SSE‑стрим** приходит первым событием с мета‑данными: список источников (document + page + цитата) и флаг `is_found:true`.
  4. Поток токенов ответа trickles вниз под строку `🔍 Ищу ответ в материалах курса.`.
  5. После `[DONE]` под ответом появляются кнопки **Копировать**, **Да** / **Нет** (обратная связь).
  6. При нажатии **Да/Нет** отправляется `POST /api/feedback`; появляется текст «Спасибо за отзыв!» и фокус перемещается к родительскому элементу для скринридеров.
  7. Если источников не нашлось, meta‑событие приходит с `is_found:false`; UI скрывает блоки источников и устанавливает статус «Нет в материалах».
- **Пост‑условия**: AI‑карточка `.ai-card` добавлена в `#messagesContainer`, фокус перемещен на карточку, запись о вопросе/ответе может быть сохранена в `feedback.jsonl`.

## UC‑3: Учитель загружает новый материал
- **Актор**: Преподаватель (роль `teacher` или `guest` с `ALLOW_GUEST_WRITES`).
- **Контекст**: Учитель открывает панель материалов (sidebar) кликом по иконке «Открыть панель материалов».
- **Действия**:
  1. В sidebar появляется кнопка **«Добавить PDF или TXT»** (в скрытом инпуте `#fileInput`).
  2. Учитель выбирает файл → отправляется `POST /api/documents/upload`.
  3. backend: валидирует расширение, сохраняет файл в `./data/docs/`, вызывает `load_and_chunk_file`, индексирует чанки в ChromaDB.
  4. Возвращается `{"status":"ok","filename":"...","indexed_chunks":N}`.
  5. Фронтенд вызывает `GET /api/documents`, получает обновленный список файлов и общее число чанков.
  6. `applyOnboardingAvailability(true, true)` скрывает блок примеров Onboarding, показывает текст *«Материалы ещё не загружены»* (для студентов) или текст для учителя *«Добавьте PDF или TXT — после этого здесь появятся примеры вопросов»*, и раскрывает кнопку **Добавить PDF или TXT** (доступна только учителю).
  6. Студенты могут теперь выбирать sample‑вопросы, которые будут брать контекст из только что загруженных материалов.
- **Пост‑условия**: `hasCourseDocuments === true`; наboarding‑примеры скрыты; upload‑button видим только для роли, имеющей права.

## UC‑4: Учитель удаляет документ
- **Актор**: Учитель с правами управления.
- **Действия**:
  1. В списке документов (панель материалов) нажимает кнопку **×** у нужного файла.
  2. Вызывается `DELETE /api/documents/{filename}`.
  3. Backend удаляет чанки из Chroma, удаляет файл из `./data/docs/`, возвращает `{"status":"deleted", …}`.
  4. Фронтенд обновляет список файлов и количество чанков.
- **Пост‑условия**: Документ исчез из интерфейса и из векторного хранилища.

## UC‑5: Очистка диалога
- **Актор**: Любой пользователь с активным чатом.
- **Действия**:
  1. Нажимает кнопку **Очистить диалог** (видна в шапке или через команду).
  2. Появляется подтверждение «Очистить диалог? Это действие нельзя отменить.»
  3. Пользователь подтверждает → `activeController.abort()` останавливает любой pending‑стрим.
  4. `messages.innerHTML = welcomeHtml()` (простое приветствие).
  5. Фокус перемещается в `#messagesContainer` (теперь `tabindex="-1"`).
  6. Сообщение статуса «Диалог очищен.» появляется под шапкой.
- **Пост‑условия**: Диалог сброшен, фокус на контейнере, Onboarding снова можно вызвать по кнопке помощи.
